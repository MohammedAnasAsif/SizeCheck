# Brands wanted

These brands are not in the shared dataset yet. Most publish their size chart only as an image, only inside each product page, or on pages that block automated reading, so they need a person to copy the chart. Pick one, follow [CONTRIBUTING.md](../CONTRIBUTING.md), and open a pull request or an [issue](https://github.com/MohammedAnasAsif/SizeCheck/issues/new?template=add-brand.yml).

Until a brand is added, anyone can still get a size for it in the app with *Add a size chart* (paste the chart from the product page).

Tick a brand when its file lands in `data/brands/`.
